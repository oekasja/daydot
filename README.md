# DayDot

DayDot is a simple, minimalist micro-journaling and life-tracking app. It helps you log your daily thoughts briefly (capped at 280 characters) and visualizes your total days lived using a symmetrical calendar grid layout. 

Past days are rendered cleanly as solid blocks, while future days and pre-birth dates are shown as faint ghost cells just to keep the calendar layout visually consistent.

## Built With

* Kotlin
* Jetpack Compose (Material 3)
* Gradle
